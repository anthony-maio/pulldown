Features

Fetch, extract, and inspect.

01
HTTP-First Fetching

HTTPX fetches the page; extraction and Markdown conversion run locally. Chromium rendering is an optional extra for content that needs JavaScript.

HTTPX / optional Chromium
02
Detail Levels

Five modes let you choose plain text, readable or structured Markdown, full-page Markdown, or raw HTML. Compare the output with the source before choosing a mode.

minimal / readable / structured / full / raw
03
Batch Fetching

Pass a list of URLs and get back a list of results. Concurrency controlled, errors surfaced per-item, not globally.

concurrent · per-item errors
04
Bounded Crawl

Follow links from a seed URL with explicit depth, page, and concurrency limits. Crawls stay on the same domain by default.

depth · page-limit · same-domain
05
Validator Caching

Enable a page cache to reuse results and send ETag or Last-Modified validators when rechecking a page. Cache entries are separated by detail mode.

ETag · Last-Modified · 304
06
SSRF Guard

Checks URLs and resolved addresses, rejecting private, loopback, and link-local destinations by default. Deployment network controls still matter.

SSRF · pre-connect · IP check
Detail Levels

One source. Five ways to extract it.

Version 0.4.2 accepts detail in Python and --detail in the CLI. These are mode guides; the example gallery shows saved output beside the source pages and commands that produced it. 

pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail minimal

Title and plain text for a first pass or summary. Check that removing links and structure still leaves enough context for your task.

pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail readable --json-output

The default mode chooses an extraction strategy from the page structure. It favors article text on narrative pages and can route listings or dashboards to structured extraction. Inspect meta.routing in the JSON result.

pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail structured

Preserves hierarchy and summarizes tables for listings, dashboards, and documentation. Compare the retained headings, links, and rows with the source before using it for a detailed lookup.

pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail full

Converts the full page to Markdown, including navigation and footer content. Useful when the relevant text is outside an article body; expect more page chrome.

pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail raw

Returns HTML without Markdown extraction. With --render, the returned HTML is the browser's serialized DOM. Use it to inspect the source or apply your own parser.

Quick Start

Install. Fetch. Done.

Requires Python 3.10 or newer. Begin with the article fixture, then render the JavaScript listing to see when a browser is needed.

Install and fetch
python -m pip install "pulldown==0.4.2"
pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail readable
pulldown get https://pulldown.making-minds.ai/examples/field-notes.html --detail structured
Render the JavaScript example
python -m pip install "pulldown[render]==0.4.2"
python -m playwright install chromium
pulldown get https://pulldown.making-minds.ai/examples/live-board.html --render --detail structured

The gallery includes the HTTP-only output for comparison. Installing the render extra and Chromium are separate steps. Rendering requires a canonical URL: redirects, workers, and WebSockets are blocked.

Python API
import asyncio
from pulldown import fetch, Detail

async def main():
    result = await fetch(
        "https://pulldown.making-minds.ai/examples/field-notes.html",
        detail=Detail.structured,
    )
    if not result.ok:
        raise RuntimeError(result.error or result.status_code)
    print(result.content)
    print(result.meta.get("routing"))

asyncio.run(main())

Security

Explicit network and content limits.

URL checks and response limits reduce exposure when accepting a URL from a user or agent. These are network policy guards, not process isolation; set appropriate network and resource limits for the service running them.

SSRF Guard

Private, loopback, link-local, and reserved addresses are rejected by default. Ordinary HTTP fetching checks redirect targets before following them. Browser rendering rejects redirects; use the final canonical URL. Keep private-address access disabled when handling untrusted URLs.

address checks / HTTP redirect validation / explicit override
Size Caps

The default content limit is 10 MiB, configured with max_bytes or --max-bytes. HTTP responses are size-checked; rendering checks the serialized DOM after the browser loads it. This does not cap browser or process memory.

HTTP response cap / rendered DOM limit / configurable threshold
Scheme Validation

Only http:// and https:// URLs are accepted. file://, gopher://, ftp://, and other schemes are rejected before a connection is attempted.

scheme allowlist · early rejection · redirect chain validated

import asyncio

From URL to result

Keep the extraction decision visible.

A successful fetch does not guarantee that the output contains everything your task needs. The result includes status, content, errors, and routing metadata so you can inspect the decision and choose another mode.
